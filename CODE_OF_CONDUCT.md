# Code of Conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful and constructive. To report unacceptable behaviour, contact the maintainers through a private
[GitHub Security Advisory](https://github.com/nochaosio/jaegershim-clickhouse/security/advisories/new)
or by direct message to a maintainer. Reports are handled confidentially.
